## Por que MDX?

Esta documentação usa **MDX**, que combina Markdown com React. Isso significa que você pode:

- ✅ Escrever documentação em Markdown simples
- ✅ Importar e usar componentes React reais do projeto
- ✅ Criar exemplos interativos
- ✅ Manter código e documentação sincronizados

## Como usar

1. **Navegue** pela sidebar à esquerda
2. **Edite** arquivos `.mdx` diretamente no código
3. **Veja** mudanças instantaneamente no modo dev
4. **Commit** documentação junto com código

## Contribuindo

Ao adicionar novas features ou mudanças:

1. Atualize a documentação relevante
2. Adicione novos eventos em `/docs/analytics/events`
3. Documente decisões técnicas em `/docs/app-concept`
4. Registre problemas e hipóteses em `/docs/analytics/problems/`
